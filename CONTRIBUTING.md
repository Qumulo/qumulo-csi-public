# Contributing

Thank you for your interest in the Qumulo CSI Driver.

This repository is published under the [Qumulo CSI Driver License](LICENSE),
which does not permit modifications or derivative works. For that reason we do
not accept external pull requests.

- **Questions, problems or feature requests:** open a case with Qumulo support
  at [care.qumulo.com](https://care.qumulo.com).
- **Security issues:** report them through Qumulo support rather than in a
  public issue.
- **Documentation:** the rendered site is at
  <https://qumulo.github.io/qumulo-csi-public/>.

How the driver is built and the rules its code follows are described in
[ARCHITECTURE.md](ARCHITECTURE.md).
