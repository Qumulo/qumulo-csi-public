# Features

Everything the Qumulo CSI driver supports, in plain terms. Each page below shows you how to use it.

- [Volumes](volumes.md) — create, grow and delete storage.
- [Adopt an existing folder](existing-folder.md) — hand Kubernetes data you already have on Qumulo.
- [Volume Layout Architecture](layout.md) — one shared NFS share, or one per volume.
- [Storage Connectivity and Access Control](access.md) — NFS version, who may mount, permissions, Kerberos.
- [Snapshots and restore](snapshots.md) — on demand or on a schedule.
- [Working with several Qumulo clusters](multi-cluster.md) — one installation, many arrays.
- [Disaster recovery](disaster-recovery.md) — replication to a second array. **Preview.**
- [Protocol and mount options](mount-options.md) — NFSv4.1 or NFSv3, and the options each mount carries.
- [Security](security.md) — credentials, TLS, and what is not encrypted.
- [Observability](observability.md) — metrics, dashboards and logs.
